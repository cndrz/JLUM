GitHub API Setup

To publish updates directly to Vercel, this system uses the GitHub API. Please enter a GitHub Personal Access Token (PAT) with `repo` write permissions.

  1. Go to GitHub Developer Settings
  2. Generate a new token (Classic) with the repo checkbox enabled.
  3. Paste your token below. It is stored securely in your local browser only.
